API name: /generate_personas Generates a list of TinyPerson instances based on the provided inputs. It prioritizes the API key passed as an argument, but falls back to the environment variable if none is provided (for UI use).

from gradio_client import Client

client = Client("harvesthealth/tiny_factory")
result = client.predict(
business_description="Hello!!",
customer_profile="Hello!!",
num_personas=1,
blablador_api_key=None,
api_name="/generate_personas"
)
print(result)
Accepts 4 parameters:
business_description str Required

The input value that is provided in the "What is your business about?" Textbox component.

customer_profile str Required

The input value that is provided in the "Information about your customer profile" Textbox component.

num_personas float Default:1

The input value that is provided in the "Number of personas to generate" Number component.

blablador_api_key str | None Default:None

The input value that is provided in the "Blablador API Key (for API client use)" Textbox component.

Returns 1 element
str | float | bool | list | dict

The output value that appears in the "Generated Personas" Json component
