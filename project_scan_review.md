# Project Scan Review: WebVoyager TinyTroupe Integration

## Overview
This project is an integration between **WebVoyager**, an LMM-powered web browsing agent, and **TinyTroupe**, a persona generation framework. The goal is to create a web agent that can embody specific personas (name, background, goal, tone, syntax) generated by TinyTroupe while performing web automation tasks.

## Architecture
The application follows a modular architecture with a Gradio-based frontend and a Selenium-based backend.

### 1. Frontend (`app.py`)
- **Framework**: Gradio.
- **Inputs**: URL, Task description, Business Description (TinyTroupe), Customer Profile (TinyTroupe).
- **Outputs**: Agent's view (screenshots), Agent Output (logs), Debug logs, Raw log file.
- **Mechanism**: Uses `concurrent.futures.ThreadPoolExecutor` to run the agent in a separate thread, allowing real-time log streaming to the Gradio UI via Python generators.

### 2. Core Agent Logic (`run.py`)
- **Main Entry Point**: `webvoyager_run` function.
- **Automation**: Selenium WebDriver (Chrome).
- **Workflow**:
    1.  Navigates to the target URL.
    2.  Applies persona to the system prompt if provided.
    3.  Enters a loop (max 5 iterations):
        - Captures screenshot.
        - Labels interactive elements using JS injection (`utils.py:get_web_element_rect`).
        - Sends multimodal request (screenshot + text) to GPT-4 Turbo.
        - Parses response for Thought and Action.
        - Executes Action (Click, Type, Scroll, Wait, GoBack, Google).
        - Yields logs for UI update.

### 3. Prompting System (`prompts.py`)
- **`SYSTEM_PROMPT`**: The base instructions for the web agent, detailing action formats and browsing guidelines.
- **`PERSONA_SYSTEM_PROMPT`**: A template that wraps the base prompt with TinyTroupe persona details:
    ```
    You are {persona_name}, a {background} with the goal of {goal}.
    You speak in a {tone} tone, using {syntax_style} syntax.
    ...
    {base_prompt}
    ```

### 4. Utilities and Integration (`utils.py`, `utils_webarena.py`)
- **TinyTroupe Integration**: `generate_persona` calls an external Hugging Face Space API (`harvesthealth/tiny_factory`) using `gradio_client`.
- **Vision Utilities**: Handles image resizing, base64 encoding, and element bounding box calculations.
- **Action Extraction**: `extract_information` parses LLM output into structured actions.
- **Accessibility**: Includes logic for fetching and cleaning accessibility trees (from WebArena).

## Core Components Summary
